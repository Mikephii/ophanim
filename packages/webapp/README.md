# TanStack Start + shadcn/ui

This is a template for a new TanStack Start project with React, TypeScript, and shadcn/ui.

it has a specific project ui template customized in shadcn webapp new project. installed using pnpm dlx shadcn@latest create --preset "https://ui.shadcn.com/init?base=radix&style=vega&baseColor=neutral&theme=teal&iconLibrary=tabler&font=figtree&menuAccent=bold&menuColor=default&radius=none&template=start&rtl=false" --template start
